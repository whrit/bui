# Theme Palette

This project uses a token-based palette to keep the UI calm, modern, and consistent.

## Dark mode tokens (default)
- Background: `#0B0F14`
- Panel: `#0F1620`
- Text: `#E6EDF3`
- Muted: `#9AA4AF`
- Border: `#223041`
- Accent (default indigo): `#7C5CFC`
- Good: `#3FB950`
- Warn: `#D29922`
- Bad: `#F85149`

## Accent options (config `ui.accent`)
- indigo (default): `#7C5CFC`
- blue: `#2F81F7`
- cyan: `#39C5CF`
- teal: `#2DD4BF`
- purple: `#A371F7`
- pink: `#FF7EB6`
- amber: `#F59E0B`
- green: `#3FB950`

## Light mode tokens
A simple light variant exists and can be expanded as the UI grows.
